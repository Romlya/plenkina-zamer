# ПЛЕНКИН · Замер остекления

Мобильное веб-приложение для замерщиков.

Откройте на телефоне/планшете: после деплоя на Vercel.

## Возможности
- Объект: адрес, клиент, телефон, дата, замерщик
- Окна: ширина × высота × количество (мм)
- Автоподсчёт площади м²
- Сохранение на устройстве
- Выгрузка: текст, CSV (Excel), JSON, «Поделиться»

## Для замерщика
1. Открыть ссылку в Safari/Chrome
2. «На экран Домой» — как приложение
3. Создать замер → добавить окна → Выгрузить → отправить руководителю
